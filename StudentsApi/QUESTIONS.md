# Контрольные вопросы

## 1. Что такое Web API?

Web API — это интерфейс, который позволяет приложениям обмениваться данными через HTTP-запросы.

## 2. Для чего нужен ControllerBase?

`ControllerBase` используется как базовый класс для API-контроллеров. Он предоставляет методы для формирования HTTP-ответов, например `Ok()` и `NotFound()`.

## 3. Что делает атрибут [ApiController]?

Атрибут `[ApiController]` указывает, что класс является API-контроллером. Он также помогает автоматически обрабатывать данные запросов и ошибки при их передаче.

## 4. Для чего используется [Route]?

Атрибут `[Route]` задаёт маршрут, по которому можно обратиться к контроллеру. В моей работе используется `[Route("api/[controller]")]`, поэтому запросы к контроллеру начинаются с `/api/Students`.

## 5. В чем разница между GET и POST?

GET используется для получения данных с сервера, а POST — для отправки данных на сервер и создания нового объекта. В моей работе GET используется для получения студентов, а POST — для добавления нового студента.

## 6. Что означает HTTP-код 404 Not Found?

Код `404 Not Found` означает, что запрашиваемый ресурс не найден. В моей работе такой ответ возвращается, если в списке нет студента с указанным ID.
