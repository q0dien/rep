# Task 4 — Ответы на вопросы

### 1. Что такое Web API?

Web API — это способ, с помощью которого разные программы могут обмениваться данными через интернет. Например, приложение отправляет запрос серверу, а сервер возвращает нужную информацию.

### 2. Чем HTTP Request отличается от HTTP Response?

HTTP Request — это запрос, который отправляет клиент серверу.

HTTP Response — это ответ, который сервер отправляет обратно клиенту.

Например, я отправляю запрос на получение товара, а сервер возвращает данные этого товара.

### 3. Для чего используется GET?

GET используется для получения информации. В моей работе через GET я получаю список товаров или один товар по его ID.

### 4. Для чего используется POST?

POST используется для отправки новых данных на сервер. В моей работе POST нужен для добавления нового товара.

### 5. Что означают 200 OK и 404 Not Found?

**200 OK** означает, что запрос выполнился успешно.

**404 Not Found** означает, что нужный объект не найден. Например, если я запрашиваю товар с ID, которого нет в списке.
