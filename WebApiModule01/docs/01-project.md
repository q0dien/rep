# Task 1 — Проектирование Web API

## Предметная область

Для своей работы я выбрала **товары**.

Главный объект — `Product`. Через API я могу получить список товаров, найти товар по его ID и добавить новый товар.

У товара есть 5 полей:

| Поле     | Тип     | Что хранит           |
| -------- | ------- | -------------------- |
| Id       | int     | ID товара            |
| Name     | string  | Название             |
| Category | string  | Категория            |
| Price    | decimal | Цена                 |
| Stock    | int     | Количество на складе |

Я выбрала именно эти поля, потому что их достаточно для простого примера работы с товарами.
