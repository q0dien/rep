# Task 2 — Конечные точки API

Я сделала 3 основные конечные точки для работы с товарами.

| Метод | URL               | Что делает             | Статус                 |
| ----- | ----------------- | ---------------------- | ---------------------- |
| GET   | `/api/products`   | Показывает все товары  | 200 OK                 |
| GET   | `/api/products/5` | Показывает товар по ID | 200 OK / 404 Not Found |
| POST  | `/api/products`   | Добавляет новый товар  | 201 Created            |

## GET /api/products

Используется для получения списка всех товаров.

## GET /api/products/5

Используется, чтобы получить один товар по его ID.

Если товара с таким ID нет, сервер возвращает `404 Not Found`.

## POST /api/products

Используется для добавления нового товара. Данные товара отправляются в теле запроса.

Если товар успешно добавлен, сервер возвращает `201 Created`.

При неправильных данных может вернуться `400 Bad Request`.
