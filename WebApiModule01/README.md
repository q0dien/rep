# Практическая работа Module 01 — Введение в ASP.NET Core и первая конечная точка API

## Цель работы

Цель работы — познакомиться с Web API, HTTP-запросами и HTTP-ответами, а также создать первое REST API на ASP.NET Core.

В работе я создала небольшое Web API для работы с товарами.

## Предметная область

В качестве предметной области я выбрала **товары**.

Основной ресурс — `Product`.

Каждый товар содержит следующие поля:

* `id` — уникальный идентификатор товара;
* `name` — название товара;
* `category` — категория товара;
* `price` — цена;
* `stock` — количество товара на складе.

## Реализованные endpoints

| Метод | URL               | Назначение                   |
| ----- | ----------------- | ---------------------------- |
| GET   | `/api/products`   | Получить список всех товаров |
| GET   | `/api/products/1` | Получить товар по ID         |
| POST  | `/api/products`   | Добавить новый товар         |

## HTTP-статусы

В работе используются следующие HTTP-статусы:

* **200 OK** — запрос выполнен успешно;
* **201 Created** — новый товар успешно создан;
* **404 Not Found** — товар с указанным ID не найден.

## Пример товара

```json
{
  "id": 1,
  "name": "Ноутбук Lenovo",
  "category": "Ноутбуки",
  "price": 450000,
  "stock": 10
}
```

## Результат тестирования

Я проверила работу API:

* `GET /api/products` — получил список товаров;
* `GET /api/products/1` — получил товар с ID 1;
* `GET /api/products/99` — получил статус `404 Not Found`;
* `POST /api/products` — добавил новый товар;
* после POST новый товар появился в общем списке.
