# Лабораторная работа №5 - TaskApi и TaskManagerClient

## Описание

В лабораторной работе были созданы два ASP.NET Core приложения:

* **TaskApi** - Web API для работы с задачами.
* **TaskManagerClient** - клиентское ASP.NET Core MVC приложение, которое взаимодействует с Web API через `HttpClient`.

В приложении можно получить список задач, посмотреть отдельную задачу, добавить новую задачу, изменить её и удалить.

## Web API

Адрес Web API:

`http://localhost:5179`

Основные методы:

| Метод  | Адрес             | Назначение             |
| ------ | ----------------- | ---------------------- |
| GET    | `/api/tasks`      | Получение списка задач |
| GET    | `/api/tasks/{id}` | Получение одной задачи |
| POST   | `/api/tasks`      | Добавление задачи      |
| PUT    | `/api/tasks/{id}` | Изменение задачи       |
| DELETE | `/api/tasks/{id}` | Удаление задачи        |

## IHttpClientFactory

В `TaskManagerClient` зарегистрирован именованный HttpClient с именем `TaskApi`.

В качестве адреса Web API используется:

`http://localhost:5179/`

Клиент получает HttpClient через `IHttpClientFactory`. Для выполнения запросов используются GET, POST, PUT и DELETE.
