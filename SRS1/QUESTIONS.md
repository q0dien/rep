# Контрольные вопросы

## 1. Что такое Web API?

Web API — это интерфейс, с помощью которого приложения могут обмениваться данными через HTTP-запросы.

## 2. Что такое HTTP-запрос?

HTTP-запрос — это обращение клиента к серверу для получения или изменения данных.

## 3. Что такое HTTP-ответ?

HTTP-ответ — это ответ сервера на запрос клиента. В нём может содержаться статус выполнения, заголовки и данные.

## 4. Для чего используется GET?

GET используется для получения данных с сервера. В моей работе с помощью GET я получала список студентов и данные отдельного студента.

## 5. Для чего используется POST?

POST используется для отправки данных на сервер и создания нового объекта. В моей работе POST использовался для добавления нового студента.

## 6. Что означает статус 200 OK?

Статус 200 OK означает, что запрос был выполнен успешно.

## 7. Что означает статус 404 Not Found?

Статус 404 Not Found означает, что запрашиваемый ресурс не найден. В моей работе такой ответ появился при поиске студента с несуществующим ID.

## 8. Что такое JSON?

JSON — это формат представления данных, который часто используется для обмена данными между клиентом и сервером.

## 9. Что такое endpoint?

Endpoint — это конкретный адрес API, по которому можно выполнить определённое действие. Например, `GET /api/Students` используется для получения списка студентов.

## 10. Что такое Swagger?

Swagger — это инструмент для отображения документации API и проверки HTTP-запросов. В своей работе я использовала Swagger для тестирования GET и POST запросов.
