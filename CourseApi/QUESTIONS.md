# Контрольные вопросы и ответы

## 1. Что такое Web API?

Web API — это веб-сервис, который позволяет программам обмениваться данными через интернет с помощью HTTP-запросов.

## 2. Чем Web API отличается от обычной веб-страницы?

Обычная веб-страница предназначена в основном для пользователя и отображается в браузере. Web API предназначен для взаимодействия программ и обычно возвращает данные, например в формате JSON.

## 3. Что такое клиент-серверная архитектура?

Это архитектура, в которой клиент отправляет запрос серверу, а сервер обрабатывает его и возвращает ответ.

## 4. Что такое HTTP-запрос?

HTTP-запрос — это сообщение, которое клиент отправляет серверу для выполнения определённого действия.

## 5. Что такое HTTP-ответ?

HTTP-ответ — это сообщение сервера клиенту, которое содержит результат обработки запроса и статус выполнения операции.

## 6. Что такое endpoint?

Endpoint — это конкретный адрес API, по которому можно выполнить определённую операцию.

Например:

`GET /api/Courses`

## 7. Что делает HTTP-метод GET?

GET используется для получения данных с сервера.

## 8. Что делает HTTP-метод POST?

POST используется для создания и добавления новых данных.

## 9. Чем PUT отличается от POST?

POST обычно используется для создания нового объекта, а PUT — для изменения уже существующего объекта.

## 10. Что делает HTTP-метод DELETE?

DELETE используется для удаления данных с сервера.

## 11. Что означает статус-код 200?

`200 OK` означает, что запрос был успешно выполнен.

## 12. Что означает статус-код 201?

`201 Created` означает, что новый объект был успешно создан.

## 13. Что означает статус-код 204?

`204 No Content` означает, что запрос выполнен успешно, но сервер не возвращает содержимое в ответе.

Например, такой статус я получила после удаления курса.

## 14. Что означает статус-код 404?

`404 Not Found` означает, что запрашиваемый ресурс не найден.

В моей работе этот статус появился при запросе курса с несуществующим ID и после удаления курса.

## 15. Что такое JSON?

JSON — это простой текстовый формат для хранения и передачи данных между программами.

Например:

```json id="y2x0fu"
{
  "id": 1,
  "name": "Web Services",
  "teacher": "Teacher 1",
  "credits": 5
}
```

## 16. Для чего используется атрибут [HttpGet]?

`[HttpGet]` указывает, что метод контроллера должен обрабатывать HTTP GET-запрос.

## 17. Для чего используется атрибут [Route]?

`[Route]` задаёт маршрут, по которому можно обратиться к контроллеру или его методу.

В моей работе используется:

`[Route("api/[controller]")]`

Поэтому контроллер `CoursesController` доступен через `/api/Courses`.

## 18. Что такое ControllerBase?

`ControllerBase` — это базовый класс для API-контроллеров ASP.NET Core. Он содержит методы, которые позволяют возвращать HTTP-ответы, например `Ok()`, `NotFound()` и `NoContent()`.

## 19. Что такое Swagger?

Swagger — это инструмент для просмотра и тестирования API. С его помощью можно увидеть доступные endpoint'ы и выполнять HTTP-запросы через браузер.

## 20. Почему Web API удобно использовать для взаимодействия нескольких систем?

Web API позволяет разным программам и системам обмениваться данными через стандартные HTTP-запросы. Поэтому одна система может получать или отправлять данные другой системе независимо от того, на каком языке она написана. Например, мобильное приложение может отправить запрос серверу и получить данные через API. Поэтому разные системы могут взаимодействовать между собой независимо от используемой технологии.
