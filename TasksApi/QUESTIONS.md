# Контрольные вопросы

## 1. Что такое Web API?

Web API — это интерфейс, который позволяет приложениям обмениваться данными через HTTP-запросы. Например, клиент может отправить запрос серверу, а сервер вернёт данные в формате JSON.

## 2. Для чего используется атрибут [ApiController]?

Атрибут `[ApiController]` показывает, что класс является API-контроллером. Он также помогает автоматически обрабатывать данные запроса и проверять их корректность.

## 3. Для чего используется [Route]?

Атрибут `[Route]` задаёт адрес, по которому можно обратиться к контроллеру. В моей работе используется `[Route("api/[controller]")]`, поэтому адрес начинается с `/api/Tasks`.

## 4. Чем отличаются методы GET и POST?

GET используется для получения данных с сервера, а POST — для отправки данных на сервер и создания нового объекта. В моей работе GET используется для получения задач, а POST — для добавления новых задач.

## 5. Чем отличаются PUT и DELETE?

PUT используется для изменения существующего объекта, а DELETE — для его удаления. В моей работе PUT изменяет данные задачи, а DELETE удаляет задачу из списка.

## 6. Что означают HTTP-коды 200, 201, 400 и 404?

`200 OK` означает, что запрос успешно выполнен.

`201 Created` означает, что новый объект был успешно создан.

`400 Bad Request` означает, что сервер получил некорректный запрос или данные.

`404 Not Found` означает, что запрашиваемый объект не найден.
